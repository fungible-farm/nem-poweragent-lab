# data/

This directory is populated by `scripts/fetch_csiro_nem_data.py` and is gitignored except for this
file — the CSIRO Synthetic-NEM-2000-Bus MATPOWER case files are pulled at install/fetch time
rather than vendored, so the repo always picks up upstream corrections and stays small.

Source: https://github.com/csiro-energy-systems/Synthetic-NEM-2000bus-Data (CC-BY 4.0).
